Step 2 · How PHP serves visitors

Think of PHP like a hotel

🧳Guest 1a web request
→
🛏️Room 101a PHP “worker”
→
🧹Housekeepingreset the memory
→
🧳Guest 2the next request

A server has only a few rooms (workers). Each room is reused guest after guest. That's fast, and it's safe only if housekeeping does its job.

🏨 Golden rule: clean the room before the next guest checks in.
